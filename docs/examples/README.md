# Example configs

Copy one to the participant data folder as `config.json`.

`config.2017-study.json`: the settings and look of a 2017 lab study. No calibration,
neighborhood drop mode (size 3, always change lane), 3 blocks of 300 balls, a ball every
400 ms, ball speed 0.01 (about 1 s to fall), the clean look with full-height flames and flat
ball and paddle.
