# Assets extracted from the original C4 build

Generated by `tools/c4-assets/extract.py` from a `BallDropGame` checkout. Do not edit these
by hand; rerun the script.

| File | Source | Used for |
|---|---|---|
| `sky/bright/0..5.png` | `old_data_GTBallDrop/sky/Bright1..6.tex` (identical to C4's `Data/Demo/sky`) | skybox of the pre-Oct-2012 worlds, in C4 face order +X −X +Y −Y +Z −Z |
| `texture/red_flame.png` | `Data/GTBallDrop/texture/red_flame.tex` | fire pits, clean world |
| `texture/Flame.png` | `old_data_GTBallDrop/texture/Flame.tex` | fire pits, classic world |
| `texture/blue_flame.png` | `Data/GTBallDrop/texture/blue_flame.tex` | a missed ball on fire |
| `texture/Wall.png` | `old_data_GTBallDrop/texture/Wall.tex` | `new_wall` material: ground, pit walls, dividers |
| `texture/noise.png` | `Data/C4/C4/noise.tex` | the C4 fire shader's distortion noise |

Rows are in C4's stored order (first row = v 0), so load them with `flipY = false`.

**Licensing:** the sky, noise, Flame and Wall textures are Terathon C4 Engine content
(stock demo and engine data). They were licensed for games built with C4. Check that the
lab's C4 license covers using them in this port before publishing or distributing it. The
flame textures made for GT Ball Drop (red_flame, blue_flame) are the lab's own.
