# The lab's own textures from the C4 version

Generated by `tools/c4-assets/extract.py` from a `BallDropGame` checkout. Don't edit these by
hand; rerun the script.

| File | Source | Used for |
|---|---|---|
| `texture/red_flame.png` | `Data/GTBallDrop/texture/red_flame.tex` | fire pits (and, recoloured, the classic look's yellow pits) |
| `texture/blue_flame.png` | `Data/GTBallDrop/texture/blue_flame.tex` | a missed ball on fire |

Rows are in C4's stored order (first row = v 0), so load them with `flipY = false`.

Everything else in the scene (the sky, the fire shader's noise, the gravel on the ground,
walls and poles) is generated procedurally (`src/procedural.ts`, and the sky shader in
`src/renderer.ts`). No C4 engine or stock content is included.
