# Flame textures

Drawn by Jeff Wilson in 2010 for the original GT Ball Drop.

Generated by `tools/c4-assets/extract.py` from a `BallDropGame` checkout. Don't edit these by
hand; rerun the script.

| File | Source | Used for |
|---|---|---|
| `red_flame.png` | `Data/GTBallDrop/texture/red_flame.tex` | fire pits (and, recoloured, the classic look's yellow pits) |
| `blue_flame.png` | `Data/GTBallDrop/texture/blue_flame.tex` | a missed ball on fire |

Rows are in C4's stored order (first row = v 0), so load them with `flipY = false`.

The sky, the fire shader's noise and the gravel are generated procedurally
(`src/procedural.ts`, and the sky shader in `src/renderer.ts`).
